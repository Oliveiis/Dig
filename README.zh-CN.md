# Dig · 走进街角的小发现

[English](./README.md) | 简体中文

**帮你在路过一家店时，找到值得走进去的理由。**

Dig 是一款面向城市漫游者的美食探索产品。它把附近的小店、简短的推荐理由和个人收藏放在一张地图上，让一次没有明确目的地的散步，也能自然地找到下一站。

当前以香港西营盘为体验街区，提供面向移动端的交互 Demo。

## 从“附近有什么”到“这家适不适合我”

想喝杯咖啡、吃点东西的时候，人们往往要在地图上找位置、去内容平台读推荐，再回到地图确认路线。信息很多，眼前这家店为什么值得去，却未必能迅速说清。

Dig 关注的就是这个临街决策的瞬间：**先帮助用户判断，再帮助用户发现更多。**

它为喜欢城市散步、愿意尝试街坊小店的人而设计，也适合来到陌生街区、希望就近找一顿好吃的旅行者。“几秒内理解一家店的吸引力”是产品希望实现的体验目标，仍需通过用户体验验证。

## 一次散步，可以这样开始

**打开漫游，先看看街角。** 进入后直接看到西营盘，无需先授权定位。咖啡、烘焙、中餐、日料、西餐等用不同食物图标呈现；拖动和缩放地图时，店铺聚合与分类数量随视野变化，避免密集小店挤成一团。

**让一个具体理由吸引你。** 店铺上方的轻量胶囊轮播上新、必吃推荐或活动卖点，图标随内容变化。一句“新品牛角包上线”配上 🥐，比单独一个店名更容易让人产生探索的念头。点开胶囊或门店，可以继续查看店铺详情与已有信息。

**犹豫的时候，先收起来。** 右上角可以搜索店名、查看收藏；点击底部品类，可以展开半屏店铺列表。照片、简短介绍与分类放在一起，方便比较，又能保留地图上下文。

**去过之后，让发现留下痕迹。** 打卡记录一次体验，点亮对应主题的印章；在日志里写下自己的手记，也可以把社区示例中的店铺清单加入收藏。那些“以后想去”的地方，由此成为下一次散步的起点。

## 三个入口，各自服务一个时刻

| 入口 | 用户想做什么 | 产品如何回应 |
| --- | --- | --- |
| 漫游 | 现在去哪儿吃？ | 地图发现、卖点胶囊、品类列表、搜索与收藏 |
| 日志 | 把喜欢的地方留下来 | 主题集章、店铺收藏集、社区灵感与个人手记 |
| 我的 | 看看自己走过哪里、喜欢什么 | 个人资料、探索统计、口味人设与到访足迹 |

收藏承接尚未出发的兴趣，打卡与手记记录真实发生过的体验。两者放在一起，让探索从一次选择延伸为持续积累的个人城市地图。

## 设计上的几个取舍

- **把地图留给街区。** 长篇内容进入详情，地图只展示少量短卖点；分类栏保持轻薄，缩放时调整信息密度。
- **用食物建立直觉。** 品类图标帮助识别，店铺实拍帮助比较，文案承担“为什么值得去”的解释。
- **让记录有一点收集的乐趣。** 照片拼贴、到访印章与手记，给收藏增加记忆感；印章按打卡记录点亮。
- **清新，但不抢走内容。** 清透白、浅雾蓝和少量食物暖色，搭配轻量毛玻璃与圆润字体，让店铺和食物成为视觉重点。

## 现在可以体验到什么

当前版本聚焦西营盘的完整体验流程：发现店铺 → 查看详情 → 收藏 → 打卡集章 → 留下手记。地图收录 120 个食物类地点，已有 10 家接入可追溯来源的店铺实拍，其余明确标记为待补图片。

这是用于展示和验证产品方向的 Demo。店铺位置来自地图资料；卖点、优惠、榜单排序和社区故事为演示内容，不代表实时活动、真实平台排名或真实用户评价。收藏、打卡和手记保存在当前设备，尚未提供跨设备同步与真实社区发布。地点资料与历史照片也不保证门店当前营业状态。

下一步希望优先验证：用户能否从短卖点中判断店铺是否适合自己，密集街区的地图是否仍容易浏览，以及收藏与集章是否能促成下一次探索。同时逐步补齐店铺照片、推荐依据与信息时效。
